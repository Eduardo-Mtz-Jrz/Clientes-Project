# Clientes-Project 🚀
Este proyecto es una aplicación integral para la gestión de clientes, desarrollada con una arquitectura moderna de tres capas, totalmente contenedorizada con Docker para facilitar su despliegue y escalabilidad.

## 🏗️ Arquitectura del Sistema
El proyecto está dividido en tres componentes principales que se comunican entre sí:
* Frontend (Angular): Interfaz de usuario reactiva y moderna que consume servicios del backend.
* Backend (Java & Spring Boot): API REST robusta encargada de la lógica de negocio y la persistencia de datos.
* Database (MySQL): Almacenamiento persistente de la información de los clientes mediante consultas optimizadas.

## 🛠️ Stack Tecnológico
* Frontend: Angular, TypeScript, Bootstrap.
* Backend: Java, Spring Boot, Spring Data JPA, Hibernate.
* Base de Datos: SQL (MySQL).
* DevOps: Docker & Docker Compose.
